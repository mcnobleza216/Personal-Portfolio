Profile

A software developer whose skillset has been built across a range of transactional systems, management systems, mobile applications, and enterprise web platforms — translating business requirements into scalable technical solutions and automating manual processes along the way.

Comfortable across the stack: VB.NET, ASP.NET, C#, and Java on the backend within an MVC framework; HTML, CSS, JavaScript, and API integration on the front end; and Microsoft SQL Server on the data side, from stored procedures and views to query optimization.
